# آخرین ایستگاه — Prototype

نسخه اولیه مرورگری پروژه PROJECT: ECHO.

## اجرا
به دلیل استفاده از ES Modules، فایل را مستقیماً با `file://` باز نکنید.
در پوشه پروژه یک سرور محلی اجرا کنید:

```bash
python -m http.server 8000
```

سپس:
http://localhost:8000

## کنترل‌ها
- WASD: حرکت
- Mouse: نگاه کردن
- E: تعامل
- Shift: دویدن
- Esc: آزاد کردن ماوس

## وضعیت Prototype
فصل اول فعلاً شامل:
- جاده و باران
- خودرو
- رادیو
- ایستگاه نگهبانی
- کلید
- سه سرنخ
- مسیر مخفی
- تونل
- آزمایشگاه
- باتری، کارت دسترسی و کد امنیتی
- رایانه مرکزی
- سیستم مأموریت و Inventory

این ساختار عمداً ماژولار نگه داشته شده تا سیستم‌های Co-op، مهارت‌ها، ذخیره بازی و فصل‌های بعدی روی آن توسعه پیدا کنند.
